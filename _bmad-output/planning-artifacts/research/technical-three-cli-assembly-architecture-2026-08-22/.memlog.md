- (claim) ref=[1,4,5,6] status=verified class=compatibility pub=2026-08 Three clients have no shared exclusive config root, portable Session format, or common effective-config receipt.
- (claim) ref=[1,2] status=verified class=architecture pub=2026-08 Clearing real global config is non-transactional and unsafe under crash or concurrency; it is not an isolation contract.
- (claim) ref=[2] status=verified class=architecture pub=2026-08 The lowest relative burden is an external narrow invocation envelope implemented OMP-first, not three simultaneous full adapters or an OMP-internal core.
- (claim) ref=[3] status=verified class=implementation pub=2026-08 TypeScript with Bun standalone executable minimizes MVP language seams; Go is the first reversal target if distribution evidence blocks Bun.
- (claim) ref=[4,5,6] status=verified class=integration pub=2026-08 External config adapters cover static launch and explicit resume; hooks/extensions are needed only for runtime observation, interception, or mutation.
- (claim) ref=[1,2,4,5,6] status=verified class=state pub=2026-08 Native clients retain credentials, transcript, and Session ownership; the control plane stores only opaque locators and its own receipts.
- (contradiction) ref=[2,4] OMP --config overlay was asserted from settings documentation but not found in current CLI entry/source; final recommendation does not depend on it and marks it disputed pending release-pinned smoke.
- (decision) Choose an external TypeScript/Bun control-plane CLI with a narrow adapter port, implement OMP first, add Claude/Codex later through the same manifest and receipt contracts, and add client hooks only on demonstrated runtime-observation needs.
