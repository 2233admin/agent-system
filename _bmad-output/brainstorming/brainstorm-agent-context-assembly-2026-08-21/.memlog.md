- (idea by coach) 把 prompt/Skill 视为语义级 capability：只有客户端能证明下一轮重新解析时才允许原进程热切换。
- (idea by coach) 为每个适配器声明 capability matrix；不支持的能力必须显式报错或降级说明，禁止静默忽略。
- (idea by coach) 提供 plan/apply 两阶段命令：先展示将加载、卸载、重启和失去的能力，再真正切换。

- (idea by coach) 允许负向声明：某 profile 可以明确禁止某个 Skill、MCP、全局 prompt 或自动发现源。
- (idea by coach) 把机器级、用户级、仓库级、会话级状态分离存放，并在回执中展示每层的写入所有者。
- (idea by coach) 不把文件路径当身份；同一资产在 macOS 与 Windows 通过逻辑 URI 解析到本地实现。
- (idea by coach) 建立最小 bootstrap：客户端启动时只加载 profile 解析器、选择器和安全规则，其余能力按装配结果进入。

- (idea by coach) 把可见上下文与可执行权限解耦：Agent 可以知道某工具存在但没有调用权，也可获调用权而不注入冗长说明。
