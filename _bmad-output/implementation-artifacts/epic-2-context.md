# Epic 2 Context: 控制面发布与自更新

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

`configs`（外部 Agent System CLI）以 Bun 编译的独立可执行文件分平台发布。进程每次启动时都会在后台检查一个固定的发布端点是否有新版本；若存在，则校验其完整性并原地替换本地二进制文件。这条检查/下载/校验链路中任何一步**失败**都必须静默降级——绝不能因此阻塞或使当次启动失败，也绝不能有任何输出；但一旦替换**成功**，必须打印一行简洁提示（如版本号）告知用户已更新——失败静默与成功可见是两条独立的规则，不是同一条"不输出"禁令的两面。检查过程本身（无论成败）绝不上报任何遥测、使用数据或产品状态。这补上了一个真实缺口：负责人要求 `configs` 具备启动时自动更新能力；此前误以为参照客户端 `omp` 也是"静默原地替换二进制"，经核实 `omp` 实际是显式的 `omp update` 子命令、全程可见输出，`.bak` 文件是 Windows bin shim 的副产物而非静默更新证据——这一认知修正就是"成功必须可见"这条规则的由来。

## Requirements & Constraints

- 自更新是"日常激活绝不允许安装依赖、更改插件或联网更新"这一通用规则的一个窄范围、明确授权的例外。该例外**仅**覆盖 `configs` 自身的二进制文件，不延伸到 OMP 或薄 OMP 扩展。
- OMP 自身的版本升级仍是独立的、低频的、显式操作，门槛是 capability probe、adapter fixtures 以及 fresh→locator→explicit-resume smoke 测试后才更新兼容性快照。自更新不得触碰或影响该路径。
- 更新检查必须对单一固定的、带版本号的发布端点使用只读 GET 请求——绝不能是用户可控或运行时派生的 URL。
- 下载的资产必须先通过完整性校验（签名或已知哈希）才允许替换本地二进制。
- 替换前必须以可恢复的形式（如 `.bak` 文件）保留旧二进制，以便坏更新可以回滚。Windows 需要"先重命名旧文件、再写入新文件"的策略，因为正在运行的可执行文件不能被直接覆盖。
- **失败路径必须完全静默**：检查、下载、校验、替换任一环节失败，都必须整体降级为"本次继续使用当前版本启动"，不得抛出、不得有任何 stdout/stderr/TUI 输出、不得阻塞或延迟当前命令的执行与退出码；网络请求必须带边界超时，不得无限等待。
- **成功路径必须打印一行简洁提示**：替换成功（旧二进制已存为 `.bak`、新二进制已写入原路径）后，需在 stdout 打印一行说明已更新到的新版本号；这不是对失败静默规则的例外或违反，而是一条独立要求。该提示本身的输出/格式化失败不得影响命令继续执行或退出码，也不需要额外确认。
- 更新流程（无论检查结果、成败）不得采集或上报任何遥测、使用数据或产品状态。
- 这是整个产品中唯一允许日常激活产生联网副作用的地方。
- 测试覆盖必须包含固定端点合同、完整性校验强制执行、失败静默降级行为、成功路径的提示输出，以及零遥测。

## Technical Decisions

- **固定发布端点：** 端点就是本仓库自身的 GitHub Releases（`github.com/zaurakworks/agent-system`）。
- `configs` 继续以 Bun `--compile` 独立产物分平台发布，这是既有分发规则，本 Epic 不做改动。
- 薄 OMP 扩展的分发渠道（Marketplace、Git 或本地 link）及其"必须与 CLI 协议版本显式兼容"的要求不受本 Epic 影响；自更新只作用于 `configs` 自身的二进制文件。
- 整体系统范式是以外部 CLI 为唯一组合根的六边形模块化单体；自更新组件应遵循既有约定——adapter（更新/进程/文件系统 adapter）不做产品决定，副作用与领域核心隔离。
- 本 Epic 不引入 daemon、后台服务、队列或通用 IPC 总线——检查是进程启动时内联发生的一次性动作，不经由常驻进程。
- **"失败静默降级"与"成功打印一行提示"是两条独立规则，不是同一条禁令的两面**：失败（网络失败、校验失败、平台不支持、已是最新版本等）保持完全静默、零输出；成功替换后必须打印一行提示（如 `configs: 已更新到 vX.X.X`），不要求额外确认，也不改变命令本身的继续执行与退出码。该修正已于 2026-08-23 落地（fd6f7fa 定稿 correct-course，a8560f1 / PR #148 实现，合并于 46049d3），本 Epic 无待落地的行为修正点。
